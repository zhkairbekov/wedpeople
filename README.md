# WEDPEOPLE — Свадебные истории со вкусом (Astana • Almaty)

Премиальный веб-сайт свадебного и event-агентства полного цикла **WedPeople by Kanat Ayaganov** (`@wedpeople`, основатель — Канат Аяганов).  
Разработан в эстетике **Warm Editorial Atelier** с акцентом на выразительную журнальную типографику, современное переосмысление казахского культурного кода (*Қыз ұзату*, символ *«Қарлығаш»*), прозрачную архитектуру бюджета и мгновенную конверсию в WhatsApp.

---

## ✨ Ключевые особенности

- **Двуязычный интерфейс (`RU` / `ҚАЗ`):**
  - Полная локализация всех секций, манифеста, кейсов портфолио, состава команд (`Credits`), культурного блока и форм на русский и казахский языки.
  - Сохранение выбранного языка в `localStorage` (`wedpeople_lang`) и автоматическое обновление заголовка страницы и `<html lang="...">`.
- **Кураторское портфолио и интерактивные кейсы (`CaseDrawerModal`):**
  - Фильтрация проектов по категориям: *Все проекты*, *Свадебные торжества*, *Қыз ұзату*, *Fashion & Special*.
  - Детальная карточка каждого кейса с интерактивной фотогалереей, историей реализации и полным списком подрядчиков (`Credits`).
- **Мгновенный переход в WhatsApp (Concierge Dispatch):**
  - Формы записи в секции контактов и внутри карточек кейсов не требуют ввода телефона — при отправке сразу открывается диалог в WhatsApp (`+7 777 767 08 35`) с готовым персонализированным сообщением на выбранном языке (`RU` или `ҚАЗ`).
- **Продуманная Mobile-First адаптивность:**
  - Фиксированная (`sticky`) шапка с компактным двухстрочным логотипом, переключателем языка `RU | ҚАЗ` и плавным мобильным меню.
  - Ненавязчивая плавающая кнопка быстрой связи на мобильных экранах, которая появляется при прокрутке и автоматически скрывается у секции контактов.
  - Оптимизация под `prefers-reduced-motion` и отсутствие горизонтального скролла (`overflow-x: clip`).

## 🛠 Технологический стек

- **Фреймворк:** [React 19](https://react.dev/) (JavaScript `.jsx` / `.js`)
- **Сборщик:** [Vite 6](https://vite.dev/)
- **Стилизация:** [Tailwind CSS 3](https://tailwindcss.com/) + кастомные утилиты `hairline` и анимации в `src/index.css`
- **Иконки:** [Lucide React](https://lucide.dev/) & Google Material Symbols Outlined
- **Типографика (Google Fonts):**
  - `Playfair Display` & `Cormorant Garamond` — акцентная антиква для заголовков и цитат
  - `Manrope` — основной гротеск для текста и интерфейса
  - `Space Mono` — моноширинный шрифт для индексов, тегов и метаданных

## 🚀 Быстрый старт и команды

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск сервера для разработки
```bash
npm run dev
```
После запуска откройте адрес, указанный в терминале (по умолчанию `http://localhost:5173`).

### 3. Сборка для продакшна
```bash
npm run build
```
Готовые статические файлы будут собраны в папку `dist/`.

### 4. Предпросмотр продакшн-сборки
```bash
npm run preview
```
